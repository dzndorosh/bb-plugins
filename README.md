# bb-plugins

Плагины для [bb](https://getbb.app).

| Плагин | Что делает |
| --- | --- |
| [digest](./digest) | Карточка-сводка по наведению на тред, компактный список тредов в сайдбаре и доска needs you / done / running на экране нового треда |

## Установка

Нужен bb 0.49 или новее.

```sh
bb plugin install git:https://github.com/dzndorosh/bb-plugins.git@main --plugin digest
```

Подробности и формат сводки: [digest/README.md](./digest/README.md).
